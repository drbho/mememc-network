# 🤡 MemeSMP - Risate, Lag e Cubi

Un server Minecraft caotico e divertente dove le regole sono fatte per essere infrante!

## 🎮 Cos'è MemeSMP?

MemeSMP è un server Minecraft survival incentrato sul puro divertimento e sui meme. Dimentica i server seri con regole noiose: qui si viene per ridere, fare scherzi epici e creare momenti indimenticabili.

### Caratteristiche principali:

- **🤪 Vibes Assurde**: Gameplay libero senza regole che rovinano il divertimento
- **🎭 Community Selezionata**: Solo giocatori che sanno stare allo scherzo
- **🗑️ Zero Burocrazia**: Niente ticket infiniti, solo soluzioni rapide (e possibilmente esplosive)
- **📍 69 Slot**: Il numero perfetto per una community attiva ma gestibile

## 🚀 Come Unirsi

1. Unisciti al nostro [server Discord](https://discord.gg/HjDBbnANxQ)
2. Leggi le regole (spoiler: sono poche)
3. Preparati al caos!
